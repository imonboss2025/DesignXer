## CONTENT SPECIFICATIONS SUMMARY

### Heading Structure Best Practice
```
H1: One per page (main topic)
H2: 4-10 per page (main sections)
H3: 2-3 per H2 (subsections)
H4+: Only when necessary for clarity
```

### Keyword Distribution
Each page targets:
- 1 Primary Keyword (searched 500+ times/month, commercial intent)
- 3-5 Secondary Keywords (related terms)
- 10+ Long-tail variations (natural search queries)

### Content Length Guidelines
| Page Type | Word Count | Reading Time |
|-----------|-----------|--------------|
| Homepage | 1,200-1,500 | 4-5 min |
| Service Page | 2,000-2,500 | 8-10 min |
| Industry Page | 2,000-2,500 | 8-10 min |
| Blog Post | 1,500-2,500 | 6-10 min |
| Case Study | 1,500-2,000 | 6-8 min |

### Meta Tag Format
```
Title: Primary Keyword | Secondary Benefit | Brand Name (50-60 chars)
Description: Problem → Solution → CTA (150-160 chars)
Include primary keyword naturally in both
Focus on click-through rate (CTR)
```
