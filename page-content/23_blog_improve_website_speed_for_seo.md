## Introduction (H1)

Website speed is both a ranking signal and a conversion multiplier. This guide walks through prioritized steps to improve performance without a full rebuild.

---

## 1. Measure First (H2)

Use Lighthouse, PageSpeed Insights, and field data from CrUX to identify bottlenecks and prioritize fixes.

---

## 2. Optimize Images (H2)

Serve modern formats (WebP/AVIF), use responsive `srcset`, compress without visible loss, and implement lazy-loading for below-the-fold images.

---

## 3. Reduce JavaScript & Third-Party Impact (H2)

Defer non-critical scripts, remove unused libraries, and audit third-party tags. Prefer server-side solutions when possible.

---

## 4. Use Efficient Caching & CDNs (H2)

Set long cache lifetimes for static assets, use a CDN close to users, and implement cache busting for deployments.

---

## 5. Critical CSS & Inline Above-the-Fold Styles (H2)

Inline critical CSS to reduce render-blocking and defer the rest of the stylesheet.

---

## 6. Optimize Server Response (H2)

Use fast hosts, HTTP/2 or HTTP/3, and consider edge compute for dynamic content. Monitor TTFB and address slow endpoints.

---

## 7. Monitor & Iterate (H2)

Set up performance budgets, synthetic monitoring, and real-user monitoring (RUM) to catch regressions early.
