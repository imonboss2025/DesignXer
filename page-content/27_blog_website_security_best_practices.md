## Introduction (H1)

Security is critical to protect customer data, preserve trust, and avoid costly downtime. This guide outlines practical, prioritized security measures for SMB websites.

---

## 1. Use HTTPS Everywhere (H2)

Install a valid SSL/TLS certificate, redirect HTTP to HTTPS, and ensure mixed content is resolved.

---

## 2. Keep Software Updated (H2)

Regularly update CMS, plugins, and server software. Subscribe to security mailing lists and patch promptly.

---

## 3. Strong Access Control (H2)

Enforce strong passwords, MFA for admin accounts, and principle of least privilege for user roles.

---

## 4. Regular Backups & Recovery (H2)

Automated daily backups stored off-site with tested restore procedures and versioning.

---

## 5. Malware Scanning & WAF (H2)

Use scanning tools and a Web Application Firewall to block common attack patterns and detect compromises early.

---

## 6. Harden Configurations (H2)

Disable unnecessary services, enforce secure headers, and use secure cookie flags (HttpOnly, Secure, SameSite).

---

## 7. Incident Response Plan (H2)

Define roles, communication plans, and steps for containment, eradication, recovery, and postmortem.
